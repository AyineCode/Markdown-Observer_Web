# Markdown Observer

一个**安安静静读 markdown 文件**的小工具：在浏览器里打开，排版、配色、代码块、公式都跟 DeepSeek Harness 的聊天正文一致，外面再套一层为长时间阅读准备的壳——能换背景、有目录、能搜索、记得你读到哪。

它**只读不改**：不动你的文件，不联网，不上传任何东西。

---

## 先选一种打开方式

| 你的情况 | 用哪种 | 一句话 |
|---|---|---|
| 只想读几个 `.md` 文件；或者要把阅读器发给别人 | **A · 一个文件，双击就读** | 不用装任何东西，把文件拖进窗口就行 |
| 想读**一整个文件夹**，要目录树，还想把某一节的链接发给别人 | **B · 文件夹 + 启动器** | 起一个只在本机跑的本地服务，左侧列出整个目录 |

两种方式**读起来完全一样**，区别只有两点：「打开文件夹」这个按钮只有 A 需要（B 直接给你目录树），以及 B 可以把地址栏里的链接分享给别人。

---

## A · 一个文件，双击就读

1. 打开 `share/` 文件夹，找到 **`markdown-observer.html`**，**双击**它（推荐用 **Chrome 或 Edge**）；
   > 这个文件是**生成出来**的（仓库里不带它，因为它把用到的库和字体全内联了，有 1 MB）：跑一次 `node tools/build-share.mjs` 就有了。
2. 把 `.md` 文件**拖进窗口**，或者点窗口中间那张「打开文件」的卡片；
3. 想读一整个文件夹：点「打开文件夹」，选一个目录，左侧立刻出现这棵目录树。

这个文件是**自带一切**的：不需要安装、不需要解压、不需要联网，断网也能用。发给朋友时，把 `share/` 这个文件夹（或者只把那个 HTML）发过去就行——里面还有一份给朋友看的 `HOW-TO-OPEN.txt` 和一篇 `sample.md`，对方双击就能试。

## B · 文件夹 + 启动器

**WSL / Linux / macOS**：在终端里进到这个文件夹，然后

```sh
./start.sh ~/notes      # 打开 ~/notes 这个目录（换成你自己的路径）
./start.sh              # 不带参数 = 打开当前目录
./stop.sh               # 读完停掉
```

**Windows**：双击 **`start.bat`**（也可以把要读的文件夹**拖到它上面**，不带参数时默认打开"文档"文件夹）；用完双击 **`stop.bat`**。

> 这两种启动方式需要电脑上装了 **Node.js**（启动器会自己检查并提示）。如果不方便装，就用上面的**方式 A**——那份 HTML 不需要任何环境。WSL 里则用 `./start.sh`，走的是同一套逻辑。

启动器做三件事：找一个空闲端口（从 4321 往上试）、起一个**只监听本机**的服务、打开浏览器。地址长得像 `http://127.0.0.1:4321/`，**只有你这台电脑能访问**，局域网里别人也打不开。

重复启动不会起第二个：同一个目录已经在跑，它只会把浏览器再打开一次；换个目录再启动，它会先把旧的停掉。

## 第一次打开，界面长这样

```
┌──────────────┐  ┌──────────────────────────────────────┐
│ 阅读器    «  │  │ 文档名            🔍  自浅深  🖨      │  ← 顶栏：全局动作
│ notes     ＋ │  └──────────────────────────────────────┘
├──────────────┤  ┌──────────────────────────────────────┐
│ ＋ 打开文件   │  │                                      │
│ 打开的文档    │  │   正文（可换背景、调字号行距栏宽）      │
│ 全部文件      │  │   窗口顶部那条细线 = 阅读进度          │
│  ▾ docs/     │  │                                      │
├──────────────┤  └──────────────────────────────────────┘
│ 本页目录      │
│  · 一、目标   │
└──────────────┘
  ⚙ 设置  ← 全局设置住在左下角（侧栏收起后它还在）
```

左边一栏上下两截共用**同一个滚动条**（文档列表和目录再长，往下滚就行）；侧栏右上角的 `«` 收起它，收起后左上角会浮出一个小圆把它拉回来。

## 怎么读

- **打开文档**：拖进窗口、按 `Ctrl+O` 选（可以一次选多个）、点左侧「打开文件」，或者直接点左侧文件树里的文件；
- **左侧栏**：上半是「打开的文档」和整个目录的文件树，下半是**本篇目录**——点三角折叠展开，点标题文字跳过去；
- **文内搜索**：按 `/` 或 `Ctrl+F`，`Enter` 跳下一处；
- **自动记住读到哪**：每篇文档各记各的，关掉再打开回到原处；窗口顶部那条细线是阅读进度；
- **代码块**：右上角「复制」一键复制整段；
- **图片**：点一下开大图，再点一下关掉；
- **打印 / 存 PDF**：`Ctrl+P`，会自动去掉背景和侧栏，只留黑字白纸。

## 怎么调

**左下角有个「设置」**——它是全局设置，不属于某一篇文档：

- **排版**：字号（85–140%）、行距、正文宽度、是否用衬线字体、代码块要不要自动换行；
- **背景**：默认是「无背景」，也就是一层极淡的黑白渐变，跟着深浅色走；想热闹一点，可以从 8 套内置渐变里挑，或者选一张**你自己的图片**（直接拖进窗口也行）；
- **深浅色**：顶栏那个三段开关（跟随系统 / 浅色 / 深色），也可以按 `T` 键循环。

设置记在这台电脑的浏览器里：换台机器就回到默认，点「恢复默认」可以随时清空。

## 快捷键

| 键 | 作用 |
|---|---|
| `/` 或 `Ctrl/Cmd+F` | 文内搜索 |
| `Ctrl/Cmd+O` | 打开文件（可多选） |
| `Alt+1..9` | 切到第 N 个打开的文档 |
| `Alt+[` / `Alt+]` | 上一个 / 下一个文档 |
| `Alt+W` | 关闭当前文档 |
| `T` | 深浅色（跟随系统 → 浅 → 深） |
| `\` | 收起 / 展开侧栏 |
| `Enter` / `Shift+Enter` | 搜索里跳到下一处 / 上一处 |
| `Esc` | 关灯箱 → 关搜索 → 关设置 |
| `Ctrl/Cmd+P` | 打印 / 存 PDF |

> 切文档为什么是 `Alt+数字`？因为 `Ctrl+Tab`、`Ctrl+W`、`Ctrl+1` 这些都被浏览器自己占着（切标签页、关标签页），网页拦不住；`Alt` 组合在网页里是空的。

## 常见问题

**双击 HTML 后一片空白？**
换成 **Chrome 或 Edge** 打开试试。个别浏览器（或者安全软件）会拦本地文件；这个文件本身不需要网络，断网也照样能开。

**文档里的图片显示不出来？**
如果图片是"相对路径"（和 `.md` 放在一起），**双击 HTML 这种打开方式看不到**——浏览器不允许本地网页读同目录的文件，这是浏览器的规矩，不是文件坏了。用方式 B，或者点「打开文件夹」，图片就正常了。

**点了「打开文件夹」没反应？**
这个按钮靠浏览器的一个能力，只有 **Chrome / Edge** 支持。Firefox / Safari 上会提示你改用方式 B，其余功能不受影响。

**提示端口被占用 / 服务起不来？**
先停掉旧的再启动：`./stop.sh`（Windows 双击 `stop.bat`）。启动器自己也会顺着 4321、4322……往下找空闲端口。

**双击 `start.bat` 一闪而过 / 提示要装 Node.js？**
装上 [Node.js](https://nodejs.org) 再双击一次就行；不想装的话直接用方式 A 的那份 HTML，功能一样。

**怎么知道服务还开着、地址是多少？**
启动时终端里会打印地址；同一目录下 `.markdown-observer.pid` 里也记着 PID、端口和文档目录。

**关不掉服务怎么办？**
`./stop.sh`（Windows 用 `stop.bat`）。如果你是在 Windows 上双击 `start.bat` 起的，关掉那个最小化的命令行窗口也一样。

**它会联网吗？会不会把我的文档传出去？**
不会。所有用到的库（代码高亮、公式、消毒）都在本地文件里，页面不发起任何网络请求；服务只监听 `127.0.0.1`，只有本机能访问。

**能编辑文档吗？**
不能，这个工具只用来读。改内容请用你平时的编辑器。

**支持哪些写法？**
标准 markdown + 表格 / 任务列表 / 删除线 / 脚注，公式支持 `$...$` 和 `$$...$$`。**不支持 mermaid 图**（DeepSeek Harness 本身也不支持）。

**它不做什么？**
不编辑、不保存、不改你的文件；不上传、不联网、不统计；也没有云同步——设置只留在这台电脑的这个浏览器里。
