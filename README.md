# Markdown Observer

_DeepSeekちゃん可愛いよ❣_

一个**安安静静读 markdown 文件**的小工具：在浏览器里打开，排版、配色、代码块、公式均与 DeepSeek 聊天正文一致，外面再套一层为长时间阅读准备的壳——**能换背景**、有目录、能搜索、记得你读到哪。

**只读不改**，不动文件，不联网，不上传任何东西。

---

## Windows

**① 安装程序**

在 Release 中下载 Markdown-Observer-Installer.exe，双击 → 选安装位置 →（可选）勾开机自启 → 装完。**自带 Node 运行时**，目标电脑不需要装任何东西。卸载走「设置 → 应用 → Markdown Observer」，会有确认。

**② 从源码安装**

```sh
node tools/win/install.mjs      # 装
node tools/win/status.mjs       # 看看服务在不在
node tools/win/uninstall.mjs    # 卸
```
这个模式让服务跑在 **WSL** 里、读仓库里这份源码——**改完代码刷新浏览器就生效**，适合自己改着玩。

装完之后，安装目录里那份 README 就是这份说明；想双击直接打开，右键任意 .md → 打开方式 → 选择其他应用 → Markdown Observer，勾上「始终」（Windows 不允许程序自己抢默认，这一下得你自己点）。

装好之后你会得到：

- **双击 .md** 直接打开（Windows 11 不允许程序自己抢默认，第一次要在「打开方式」里选一次 Markdown Observer 并勾「始终」）；
- **右键任何 .md** → 「用 Markdown Observer 阅读」，不用改默认也能用；
- **托盘图标**（通知区域）：左键开一个新的阅读页；右键 → 打开文件… / 打开文件夹… / 退出；
- 「打开文件」和「打开文件夹」用的是**系统那个新式窗口**（和浏览器弹的是同一个），选完由服务端扫描——大文件夹也是秒开。

**关于开机自动启动**：默认**关闭**，在 设置 → 行为 里改。
开启时，双击 .md 时**不用现起后台服务**（省 1～2 秒），代价是开机常驻一个后台进程（实测约 60 MB 内存）。

## HTML模式

从 Release 里下载 **`markdown-observer.html`**，**双击**它（推荐 **Chrome 或 Edge**）。这一个文件自带一切：库、字体全在里面，不用装、不用解压、不用联网。

然后把 `.md` **拖进窗口**，或者点中间那张「打开文件」卡片。想读一整个文件夹，点「打开文件夹」——左侧立刻长出目录树（连子目录一起读）。

> 这个 HTML 是**生成出来**的，仓库里不带它。要从源码生成：`node tools/build-share.mjs`。

## 自己启动一个服务

**WSL / Linux / macOS**：进到这个文件夹，

```sh
./start.sh ~/notes      # 读 ~/notes 这个目录（换成你自己的路径）
./start.sh              # 不带参数 = 读当前目录
./stop.sh               # 读完停掉
```

**Windows**：双击 **`start.bat`**（也可以把要读的文件夹**拖到它上面**）；用完双击 **`stop.bat`**。

启动器会起一个**只监听本机**的服务，然后打开浏览器，地址是 `http://127.0.0.1:47821/`——**只有你这台电脑能访问**，局域网里别人打不开。

> 端口是**固定**的 47821，这一点是有意的：浏览器的设置、背景图、阅读位置都是按「地址含端口」记的，端口一变，你会觉得「我的设置全丢了」。端口上已经跑着自己的服务时，新来的一篇会**交给它**，不会再起一个。

## 界面长什么样

```
┌──────────────┐  ┌──────────────────────────────────────┐
│ 阅读器    «  │  │ 文档名            🔍  自浅深  🖨      │  ← 顶栏：全局动作
├──────────────┤  └──────────────────────────────────────┘
│ ＋ 打开文件   │  ┌──────────────────────────────────────┐
│ WORKSPACE    │  │                                      │
│ 📁 notes  ＋ │  │   正文（可换背景、调字号行距栏宽）      │
│  ▾ docs/     │  │   窗口顶部那条细线 = 阅读进度          │
│ 打开的文档    │  │                                      │
│  a.md     ×  │  │                                      │
├──────────────┤  └──────────────────────────────────────┘
│ 本页目录      │
│  · 一、目标   │
└──────────────┘
  ⚙ 设置  ← 全局设置住在左下角（侧栏收起后它还在）
```

左边从上往下：**打开文件** → **WORKSPACE**（当前文件夹：那一行显示名字，右边的 ＋ 打开或换一个）→ 文件夹树 → **打开的文档** → **本页目录**。

文件夹树和「打开的文档」各自限高，超过了在自己的框里滚——所以一棵大树不会把下面的目录区挤没。两块之间、以及它和「本页目录」之间各有一条分割线。侧栏右上角的 `«` 收起整个侧栏，收起后左上角会浮出一个小圆把它拉回来。

## 怎么读

- **打开文档**：拖进窗口、`Ctrl+O` 选（可多选）、点「打开文件」，或者直接点文件树里的文件；
- **文档里的链接**：指向另一篇 markdown 的链接**在阅读器里就地打开**（不会跳出去或者变成下载），`#小节` 是页内跳转，`http(s)` 开新标签页；
- **本篇目录**：点三角折叠展开，点标题文字跳过去；
- **文内搜索**：`/` 或 `Ctrl+F`；
- **记得读到哪**：每篇各记各的，关掉再打开回到原处；窗口顶部那条细线是进度；
- **代码块**右上角「复制」一键复制；**图片**点一下开大图；
- **打印 / 存 PDF**：`Ctrl+P`，自动去掉背景和侧栏。

## 怎么调

**左下角的「设置」**：

- **排版**：字号（85–140%）、行距、正文宽度、衬线字体、代码块自动换行；
- **背景**：默认「无背景」（一层极淡的黑白渐变，跟着深浅色走）；想热闹点可以从内置渐变里挑，或者选一张**你自己的图片**（拖进窗口也行）；
- **行为**（服务模式下才有）：双击 md 时复用标签页还是新开、开机自动启动、高级里是「扫描时忽略的文件夹名」；
- **深浅色**：顶栏的三段开关，或者按 `T` 循环。

设置记在这台电脑的浏览器里（同一个地址才认）；点「恢复默认」随时清空。

## 快捷键

| 键 | 作用 |
|---|---|
| `/` 或 `Ctrl/Cmd+F` | 文内搜索 |
| `Ctrl/Cmd+O` | 打开文件（可多选） |
| `Alt+1..9` | 切到第 N 个打开的文档 |
| `Alt+[` / `Alt+]` | 上一个 / 下一个文档 |
| `Alt+W` | 关闭当前文档 |
| `T` | 深浅色（跟随系统 → 浅 → 深） |
| `\\` | 收起 / 展开侧栏 |
| `Enter` / `Shift+Enter` | 搜索里跳到下一处 / 上一处 |
| `Esc` | 关灯箱 → 关搜索 → 关设置 |
| `Ctrl/Cmd+P` | 打印 / 存 PDF |

## 常见问题

**双击 HTML 后一片空白？**
换成 **Chrome 或 Edge**。个别浏览器（或者安全软件）会拦本地文件；这个文件本身不需要网络，断网也能开。

**文档里的图片显示不出来？**
图片是「相对路径」（和 .md 放在一起）时，**双击 HTML 这种方式看不到**——浏览器不允许本地网页读同目录的文件，这是浏览器的规矩。用服务模式，或者点「打开文件夹」，就正常了。

**能读多大的文件夹？**
`node_modules` / `.git` / `dist` 这类目录不会出现在树里（名单可在 设置 → 行为 → 高级 改）。文件夹大到离谱时扫描会自己收手并提示「只列了前 N 篇」，不会把界面卡死。

**想读一个代码仓库？**
**用服务模式。** 那边是**服务端**扫的，直接跳过 `node_modules` —— 一个 7 万文件的仓库实测 **0.1 秒**、列出 1019 篇。
（纯浏览器模式必须把选中的文件夹**整个通读一遍**才能拿到文件，大文件夹会等很久。）

**提示端口被占用 / 服务起不来？**
`./stop.sh`（Windows 双击 `stop.bat`）停掉旧的再启动。端口固定 47821，服务自己认得出「端口上那个是我自己」，不会打架。

**双击 `start.bat` 一闪而过 / 提示要装 Node.js？**
装上 [Node.js](https://nodejs.org) 再双击一次；不想装就用那份 HTML。

**怎么知道服务还开着？**
`node tools/win/status.mjs`，或者直接开 `http://127.0.0.1:47821/`。

**安装时杀软报警了？**
大概率是**误报**：这个安装包"自解压 + 自带 node + 写自启 + 卸载时删自己"，形状上确实很像木马，
但里面只有这个阅读器和一份 Node 运行时，没有别的。想帮忙的话可以把文件提交给
[微软复核](https://www.microsoft.com/en-us/wdsi/filesubmission)（免费，选 "incorrectly detected"），
误报确认后 Defender 的库会更新。自己用的话，"更多信息 → 仍要运行"即可。

**它会联网吗？会把我的文档传出去吗？**
不会。库、字体、公式全在本地；服务只监听 `127.0.0.1`，只有本机能访问。

**能编辑文档吗？**
不能，只用来读。改内容用你平时的编辑器。

**支持哪些写法？**
标准 markdown + 表格 / 任务列表 / 删除线 / 脚注；公式支持 `$...$` 和 `$$...$$`。**不支持 mermaid**。

**它不做什么？**
不编辑、不保存、不改文件；不上传、不联网、不统计；没有云同步——设置只留在这台电脑的这个浏览器里。
也**不会**在你保存文件时自动刷新页面（评估过：只能靠轮询，在 WSL 读 Windows 文件时每次 `stat` 要 0.83 ms，为一个后台功能不值；将来若做，会走「切回窗口时刷新」那条路）。
