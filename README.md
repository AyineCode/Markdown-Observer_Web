# Markdown 阅读器

一个**在浏览器里安静读 markdown** 的小应用：排版、配色、代码块、公式全部沿用 DeepSeek Harness 聊天正文的那一套（样式表是逐条搬过来的，不是照着仿的），外面再套一层为长时间阅读做的壳——可换的背景、磨砂玻璃面板、深浅色跟随、目录、搜索、进度。

两个入口，用哪个人你定：

| 入口 | 怎么用 | 适合 |
|---|---|---|
| **静态模式** | 双击 `index.html`，把 .md 拖进去（或按 `⌘/Ctrl+O` 选文件） | 临时看几个文件；整个文件夹拷到任何机器、断网也能用 |
| **服务模式** | `node serve.mjs ~/notes` 然后打开提示的网址 | 把一个文档库长期放在里面读：左侧有文件树，地址栏会跟着文档走（可收藏、可前进后退） |

两个模式是同一套界面：服务模式只是多了一个文件列表和一条图片读取通道。

## 功能

对需求逐条落地：

### 自定义阅读背景（并且保证不影响阅读）

背景不是"铺一张图"就完事，而是三层叠加：

1. **模糊**：背景层默认 22px 高斯模糊（可调 0–48），图像细节被打散，只剩氛围；
2. **遮罩**：上面再压一层可调的遮罩（默认 30%，深色模式下自动加强到约 36%），保证正文与背景的明度差；
3. **玻璃面板**：正文装在一块半透明磨砂面板里（`backdrop-filter` + 1px 描边 + 阴影），面板不透明度可调（默认 72%）。

浏览器不支持 `backdrop-filter` 时会自动退回不透明面板——宁可少一点玻璃感，也不能糊。

背景来源三种：**8 套内置渐变**（含深色系，纯 CSS，无图片文件）、**本地图片**（拖进窗口或从设置里选；会自动等比缩到 2400px 并转成 webp 再存本地，避免撑爆浏览器存储配额）、**无背景**（纯色）。

### 深浅色与跟随系统

顶栏三段开关：跟随系统 / 浅色 / 深色；按 `T` 循环切换。机制与 dsh 完全一致——把 `data-ds-dark-theme` 属性加在 `<body>` 上，`color-scheme` 同步给浏览器（滚动条、表单控件、原生弹窗都跟着变）。跟随系统时监听 `prefers-color-scheme`，系统切换会实时响应。

### 阅读体验

- **目录**：从标题自动生成，滚动时高亮当前章节，点击平滑跳转（标题自动带 id 与滚动偏移）；
- **阅读三件套**：字号（85%–140%）、行距（0.9–1.5×）、栏宽（560–1000px，默认 **748px** 正是 dsh 聊天正文宽度）；
- **进度与位置**：顶部 2px 进度条；每篇文档各自记住上次读到的位置；
- **文内搜索**：`/` 或 `⌘/Ctrl+F` 打开，命中高亮、当前命中单独标记、上下跳转（Enter / Shift+Enter）；
- **代码块**：语言标签 + 一键复制（`⌘/Ctrl` 之外的浏览器上退回 `execCommand`），可切成不换行（横向滚动）——dsh 默认是换行的，保持一致；
- **图片**：点击开灯箱看大图（Esc 或点一下关闭）；
- **打印 / 导出 PDF**：`⌘/Ctrl+P`。打印样式会把背景、玻璃、侧栏、控件全部去掉，只留黑字白纸的正文，并避免表格/代码块被切页撕开。

## 设置项

右上角齿轮。全部存在浏览器本地（`localStorage`），下次打开还在；点"重置"回到默认。

| 项 | 默认 | 说明 |
|---|---|---|
| 外观 | 跟随系统 | 跟随系统 / 浅色 / 深色 |
| 正文用衬线字体 | 关 | 关 = dsh 那套系统无衬线；开 = 衬线（Iowan/Palatino/Georgia/宋体族） |
| 字号 | 100% | 整体缩放正文与标题（1:1 对应 dsh 的 16px/28px） |
| 行距 | 1.00× | 只影响正文行高 |
| 栏宽 | 748px | 与 dsh 聊天正文同宽 |
| 代码块自动换行 | 开 | 关掉就是横向滚动，读代码更舒服 |
| 显示侧栏 | 开 | 窄屏下侧栏会自动变成抽屉 |
| 背景 | 极光渐变 | 8 套渐变 + 无背景 + 自选图片 |
| 模糊 | 22px | 背景模糊强度 |
| 压暗 / 提亮 | 30% | 遮罩强度；深色模式下自动加强 |
| 玻璃面板不透明度 | 72% | 正文面板的通透程度 |

## 与 dsh 的保真度

**逐条搬运，并有机械校验**：`styles/markdown.css` 覆盖了 dsh 两个源样式表的**全部 137 条声明**（`MarkdownText.module.css` + `CodeBlock.module.css`），连注释里写的"为什么"都保留；五张 token 表是整file 复制的；语法高亮用 dsh 自己的 `--shiki-*` 调色板（`styles/shiki.css` + `styles/highlight-dsh.css`）。这条由 `tools/check-styles.mjs` 每次校验，缺一条就报错。

保真的细节包括：代码块 `margin: 16px 0` 但非末位时 `margin-bottom: 11px`（16/11 这对不对称是设计）、`hr` 用 1px 背景而不是 border、引用块只有左边 2px 竖线且没有下边距、表格单元格 `max-width: min(30vw, 320px)`、`h4~h6` 后接列表时收紧到 8px、行内代码 `display: inline-flex` + `font-size: 0.875em`、脚注只做编号不做跳转链接。

**有意的差异**（都是为了"读别人的文档"这个用途）：

| 差异 | dsh 的做法 | 这里的做法 | 为什么 |
|---|---|---|---|
| 原始 HTML | 一律当纯文本转义 | 用 DOMPurify 消毒后渲染 | 你读的是自己的文档，`<details>`、`<img width>` 这类写法应该能用；脚本与事件属性会被挡掉 |
| 图片 | 只允许绝对 http(s)，否则只显示 alt | 都显示，可点击放大 | 静态模式下相对路径确实无法解析（没有服务器），服务模式下会自动改写到 `/api/raw` |
| 标题锚点 | 没有 | 自动加 id | 目录与站内跳转需要 |
| 文件提及按钮 | 有（`.fileMention`） | 没有 | 那是聊天里的功能，阅读器没有宿主上下文 |
| 公式 | KaTeX 0.16.47 | KaTeX 0.18.7 | 同一族库的更新版本，排版一致 |
| 代码高亮 | shiki（TextMate 语法） | highlight.js + dsh 的调色板 | shiki 需要 WASM 与大量语法文件，且不适合 `file://` 零构建；配色与代码块外壳是一样的 |

## 目录结构

```
md-reader/
├── index.html          页面骨架（两种模式共用）
├── serve.mjs           本地服务：静态文件 + 目录树 + 文件/图片读取（零依赖，只用 node 内置模块）
├── js/app.js           全部前端逻辑（设置、主题、背景、渲染管线、目录、搜索、控件、快捷键）
├── styles/
│   ├── base.css / design-platform.css / scrollbar.css /      ← 从 dsh 整份复制
│   │   gradient-shadow-text.css / shiki.css
│   ├── markdown.css    ← dsh markdown 样式的逐条搬运（137 条声明）
│   ├── highlight-dsh.css  ← highlight.js 类名 → dsh 的 --shiki-* 语法色
│   ├── reader.css      阅读器的壳：背景、玻璃、版式、侧栏
│   └── controls.css    控件、搜索条、灯箱、响应式、打印样式
├── vendor/             第三方库（本地文件，见 NOTICE.md）
├── sample.md           示例文档（每种 markdown 元素都有）
├── sample.js           由 sample.md 生成——静态模式下不能 fetch 本地文件，所以内嵌成脚本
└── tools/
    ├── build-sample.mjs   改完 sample.md 后重新生成 sample.js
    ├── smoke.mjs          用 jsdom 把整个应用跑一遍（42/47 项断言）
    └── check-styles.mjs   保真度与 CSS 变量校验
```

## 自测

三个脚本都不需要浏览器。注意 `cwd` 要是 dsh 源码目录（借它的 `jsdom`）：

```sh
cd deepseek-harness-ayine
node ../md-reader/tools/check-styles.mjs            # 保真度 + CSS 变量（秒级）
node ../md-reader/tools/smoke.mjs                   # 静态模式：渲染/主题/搜索/设置
node ../md-reader/tools/smoke.mjs --server          # 服务模式：会自己起 serve.mjs
```

## 已知限制

- **视觉效果没有在真实浏览器里验收过**：本机没有可用的无头浏览器，所以布局/动效/磨砂质感的最后一眼需要你自己看。渲染逻辑、DOM 结构、样式是否与 dsh 一致都由上面两个脚本覆盖。
- **静态模式下少数浏览器会禁用本地存储**（`file://` 被视为不透明来源）：这时设置与阅读位置只在本次会话有效，功能不受影响。服务模式下一定可用。
- 静态模式下文档里的**相对路径图片无法显示**（浏览器不允许 `file://` 页面读同目录文件）；服务模式正常。
- 不支持 **mermaid** 图（dsh 也不支持）。数学公式支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`。
- 只做阅读，不提供编辑。

## 想改的话改哪里

| 想改什么 | 改哪 |
|---|---|
| 默认设置（字号、栏宽、背景…） | `js/app.js` 顶部的 `DEFAULTS` |
